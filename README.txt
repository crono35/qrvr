QRVR starter site

Files:
- index.html
- header.html
- footer.html
- styles.css
- site.js

Add these image files to the repository root:
- logo.webp
- campsite.webp

Important:
- Replace the # links on "Book Now" / "Check Availability & Rates" with your Campspot booking URL.
- The header and footer are loaded with JavaScript using fetch(), so preview through GitHub Pages or a local web server rather than double-clicking index.html from your computer.
